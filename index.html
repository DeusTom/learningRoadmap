How to read this roadmap

Do not read the wave number as a semester. It is only the earliest dependency depth. If your programming prerequisites for a systems block are finished, you may start that block even while an unrelated physics or breadth block from an earlier wave is still running.

A practical workload is usually 2–3 simultaneous deep lanes: for example programming/systems + mathematics/engineering + one lighter support or breadth lane.

Keep this alongside Mathematics for Computer Science: overlap in proof/logic is intentional reinforcement, while this block emphasizes philosophical argument, inference, semantics, formalization, objections, replies, and sustained argumentative writing.

Mastery evidence
  • Complete MIT 24.00 readings and handouts.

  • Construct formal proofs and explain validity, soundness, semantics, soundness, and completeness.

Overlap with Mathematics for Computer Science: Intentional reinforcement. 6.1200J develops CS-oriented proof and discrete mathematics; this block develops philosophical argumentation, inference, semantics, formalization, and sustained argumentative writing.
