Mathematics and programming start together. Independent branches progress in parallel. A knowledge block opens only after the blocks that actually supply its prerequisites are mastered—so unrelated mathematics, EE, breadth, or Windows work never becomes an artificial global gate.

How to read this roadmap

Do not read the wave number as a semester. It is only the earliest dependency depth. If your programming prerequisites for a systems block are finished, you may start that block even while an unrelated physics or breadth block from an earlier wave is still running.

A practical workload is usually 2–3 simultaneous deep lanes: for example programming/systems + mathematics/engineering + one lighter support or breadth lane.
